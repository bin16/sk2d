A 2d skeleton demo package, *JUST A TOY*.

Skeleton data defined in xml, support `halign` and `valign` to indirectly specify the location of the connection point.

Check the example:

```sh
cd examples/cat/

# will generate many frame images
# using the .sh file to merge them as gif or something
# you will need imagemagick
go run main.go
```
